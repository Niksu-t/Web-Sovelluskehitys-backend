

Miten koodasin authentication

En tiedä teinkö oikein tämän tehtävän, mutta ymmärrykseni mukaan tein. Entrien kohdalla authentication middleware tarkistaa onko käyttäjällä authorization muokkaamaan kirjausta. User muokkauksen kannalla katsotaan, että onko käyttäjä sama kuin muokattava ja sen perusteella, joko antaa muokata tai estää sen.
